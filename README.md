# Trackujemy Stoły / StolikAI (mpt_projekt)

Lokalny SPA HTML/CSS/JS łączący:

- ekran klienta (wybór restauracji, menu, rezerwacja LIVE / na dzień)
- panel pracownika **StolikAI** (pulpit, zajętość, stoliki, rezerwacje, kamery, historia detekcji)

Bez backendu i bazy — dane przykładowe są w `js/data.js`.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo serwuj katalog lokalnie:

```bash
python -m http.server 5173
```

Wejdź na http://127.0.0.1:5173

Panel pracownika: przycisk **Panel Pracownika** w nagłówku.
